# print
- You can put the executable in /usr/local/bin so it runs from anywhere or any user but you will need sudo to put it there
- if you dont have sudo you put it in your own bin directory if you dont have one you can make one ~/.local/bin, ~/bin or any other thing you have in your $PATH variable
## the executable
its an compiled ELF64 executable with optimizations it is just an compiled version of print.c and its not any different than if you were to compile print.c in the repo
